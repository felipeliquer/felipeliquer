### Olá, eu sou Luiz Felipe Liquer! 👋
**UX/UI Designer | Estudante de ADS na PUC Minas | Desenvolvedor Front-end & Mobile**

Sou um profissional multidisciplinar com mais de 15 anos de experiência em design e estratégia de marca, agora unindo esse background ao desenvolvimento de software. Atualmente, estou focado em construir soluções usando **C# .NET, SQL e React Native com Expo**.

### 🚀 Projetos Recentes
- **HotelFix:** Plataforma premiada onde atuei no levantamento de requisitos, modelagem de banco de dados e prototipagem UX.
- **Conecta Bairro:** Aplicação web com foco no desenvolvimento de wireframes, fluxos de usuário e layouts de interface.
- **ReportaAi:** Aplicativo mobile com frontend em React Native e integração com banco de dados SQLite.
